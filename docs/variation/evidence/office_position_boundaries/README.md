# Office Desk 位置变化

可选的操作路径随机采样及预设见[三短任务工作空间](../office_workspace/README.md)。本页保留原显式位置接口和原始证据。

三个短任务独立复现同一办公流程的操作。位置变化以桌面世界 XY 和各设备根为基准。范围与样点按 [场景位置工作指南](../../position/README.md) 建立，图面组织沿用 [Cabinet](../cabinet_position_boundaries/README.md) 和 [Drawer](../drawer_position_boundaries/RESULTS.md) 的整桌与等比例局部对照。

## 任务与范围

世界 +X 朝向桌内，+Y 沿桌边。所有位置字段均为根的绝对 XY（m），朝向字段为相对该型号标称朝向的桌面 +Z 转角（°）。原生采样在三项短任务中默认各轴 ±2 cm、转角 ±5°，以实际构造配置为准。候选数值统一由 [位置校验模块](../../../../tasks/office_desk/position_layout.py) 定义。

| 短任务与变化 | 标称根与候选域 | 操作、随动与边界 | 边界图 |
|---|---|---|---|
| OpenLaptop · XY | (−6.3, 0) cm，世界 XY 各 ±4 cm，连续 | 改变伸手距离及掀屏接近侧。机身、屏轴和起始半开屏沿同移，按完整机身、真实桌边和翻盖扫掠检查边界。 | [01](01_laptop_xy.png) |
| OpenLaptop · 朝向 | 同一根，−10°、0°、+10° | 沿屏沿追踪同一个接触点，翻盖动作随屏轴转。 | [02](02_laptop_yaw.png) |
| TypeKeys · XY | (−28.9, 0) cm，X −1～+2 cm、Y ±4 cm，连续 | 牵动 P/A/I/R/Enter 的按压路径与 P 目标提示。靠近桌边一侧以壳体最大转角占地为界。 | [03](03_keyboard_xy.png) |
| TypeKeys · 朝向 | 同一根，−10°、0°、+10° | 键盘和按压轴一起转，目标键及提示跟随本环境的实体。 | [04](04_keyboard_yaw.png) |
| ClickMouse · XY | (−10, −32) cm，世界 XY 各 ±4 cm，连续 | 改变右手接近侧和距左键距离。鼠标壳、左右键及滚轮随根同移。 | [05](05_mouse_xy.png) |
| ClickMouse · 朝向 | 同一根，型号标称 180° 加 −10°、0° 或 +10° | 同一左键工作点随壳体转。实测左键接近和近桌边的完整壳体占地。 | [06](06_mouse_yaw.png) |

OpenLaptop 从原生 40°～50° 初始开度开始，目标为 90° 并在 85° 以上维持四个控制步。TypeKeys 从全部键释放开始，以 P、A、I、R、Enter 顺序完成按压和释放。ClickMouse 从按钮释放开始，指定指尖在左键有效区域按下且右键未误触，连续三步达到原生条件。各短任务使用各自的实体与机器人。OfficeDeskLong 另有同时摆放三件设备的共享空间、阶段和原生抖动，短任务候选仅适用于各自独立桌面。

三件设备按原生做法固定根。支撑检查使用本体碰撞轮廓、物理桌面、原生离桌间隙和原生运行中的根漂移。OpenLaptop 另将屏幕碰撞网格绕实际关节轴从初始开度扫至 90°，作为几何分析。平移图点号与逐点表 ID 的对应关系见 [FIGURES.json](FIGURES.json)。

## 调用与遥操作

详见 [运行报告](RESULTS.md) 与 [逐点复现说明](RUN_AND_REPLAY.md)。同一任务先找 N，再找报告点名的组合点。反馈任务和样点 ID、手从哪一侧接近、在哪一步受阻、动作是否完成。完整成功仍以任务的原生判据为准。
