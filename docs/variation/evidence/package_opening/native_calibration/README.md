## 样本与条件

两个家族七入口，每入口10组，分两轮进程执行；每组分别新建渲染环境和短步环境，共70组、140次环境创建。seed7有6组，seed19和41各2组。均为Sharpa、2env、PhysX CUDA、robot noise0、外观关闭。每组两个方向局部reset，共140个前后配对。

同seed按同reset顺序比较，绝不把不同seed的合法初态变化当噪声。每个seed第一组为参考，后续组与其比较，因此每入口有7个非自比较，共49个跨重建比较；不能把首次参考行的零差也当独立重复证据。样本量不足以宣称95%/99%置信界限。

短步使用state观测、render_mode=None，动作与前次相同：每维0.01*sin(维度索引+step)，4步。完整机器人任务成功率未测。渲染阶段使用rgb+segmentation及Human相机，与前次A4/A5条件一致。

## 建议判据（待确认，未应用）

|检查项|建议数值参考|依据及边界|
|---|---|---|
|未选环境方案ID、计数、成功/阶段布尔、随机流、材质/贴图身份|必须一致|本轮没有观测到变化；不得用图像容差豁免这些变化|
|位姿、关节、速度等连续状态|暂保留各分量绝对差≤1e-6，并按量的单位分别报告|观测最大3.58e-7；1e-6是保守浮点保护带，不是统计置信上界。位置单位m、关节角rad、速度各自对应单位，不能混算成一个物理距离|
|同seed同顺序original恢复：目标区域RGB|最大通道差≤1，变化通道数≤8|原生重复实测0，保留小量化保护；没有依据放宽到41|
|未选环境普通RGB（Base/Human及未出现大波动的腕部相机）|最大通道差≤1，变化通道数≤8|覆盖本次常规原生观测；相机分别判，不跨相机累加|
|Meal舀番茄腕部RGB，多seed参考带|最大差≤3，同时变化通道数≤8、像素数≤5|覆盖观测幅值及通道/像素包络；这是可讨论的工程容差，不是已证明的随机上界。若坚持seed7专用基线，则仍只观测到≤1|
|稀疏大幅值RGB，如Meal放面包seed41的60|进入复核，不直接自动通过|不得把全局max阈值改为60。需确认位置/边界、局部性及状态/材质/RNG不变，再明确记录人工或进一步验证结论|
|相同动作短步状态|暂保留≤1e-6；奖励、终止及离散判定要求一致|本轮70条原生4步轨迹同seed重复差为0，没有数据支持将阈值放宽到1.48e-4|

阈值必须绑定入口、相机、seed范围、后端、分辨率、动作序列。对更长步数、更大并行规模或其它机器，需要重新量基线。不可只看最大RGB差，也不可只看变化通道少；两者及目标位置都要看。
