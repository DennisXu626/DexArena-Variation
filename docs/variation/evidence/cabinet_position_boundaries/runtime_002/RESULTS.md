在实测版本的环境内，用下列代码从逐点表载入任一请求。完整的构建、seed 及 reset 顺序由本次检查器的 `--followup` 分支保留；仅重建单点未独立验证全状态逐比特复现。

```python
import csv
import json
import gymnasium as gym
import torch
import tasks

with open("POINTS.csv", encoding="utf-8-sig", newline="") as f:
    row = next(r for r in csv.DictReader(f)
               if r["task"] == "CabinetPouringPickBottle-Sharpa-v1" and r["id"] == "C0")
env = gym.make(row["task"], num_envs=2, sim_backend="physx_cuda", obs_mode="state",
               reconfiguration_freq=0, **json.loads(row["make_kwargs"]))
env.reset(seed=7)
options = json.loads(row["reset_options"])
options["env_idx"] = torch.tensor([int(row["env_idx"])], device=env.unwrapped.device)
env.reset(seed=int(row["seed"]), options=options)
```
